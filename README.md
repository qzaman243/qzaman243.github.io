# qzaman243.github.io

Personal academic website of **Qamar Zaman**, built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

Live at <https://qzaman243.github.io>.

## Where things live

| What | File |
|---|---|
| Name, site settings | `_config.yml` |
| Home page (intro, photo) | `_pages/about.md`, `assets/img/prof_pic.jpg` |
| News on the home page | `_news/` |
| Publications | `_bibliography/papers.bib` |
| Projects | `_projects/` |
| CV | `_data/cv.yml` |
| Social links | `_data/socials.yml` |
| GitHub repos page | `_data/repositories.yml` |
| Fun page | `_pages/fun.md` |

The site is built and deployed by the GitHub Action in `.github/workflows/deploy.yml` to the `gh-pages` branch.
